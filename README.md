# Block-Bust Android Auto Bot (Auto.js)

Скрипт `android_autojs_block_bot.js` — это бот для Android (Auto.js), который:
- считывает поле 8x8 со скриншота,
- определяет 3 доступные фигуры,
- просчитывает порядок и позиции для всей тройки фигур (перебор перестановок),
- перетаскивает фигуру на поле.

> Важно: «бесконечно проходить» любую партию не гарантируется. Это автоигрок, который стремится жить максимально долго, но исход зависит от рандома фигур и точности калибровки.

## Что нужно

- Android-устройство.
- Установленный Auto.js (или совместимый форк).
- Разрешения: Accessibility Service + захват экрана.

## Быстрый запуск

1. Скопируйте `android_autojs_block_bot.js` на телефон.
2. Откройте в Auto.js и выдайте все разрешения.
3. Откройте игру и перейдите на экран с полем.
4. Запустите скрипт.

## Калибровка (обязательно)

Под ваше разрешение экрана нужно подстроить в `CONFIG`:

- `board.left`, `board.top`, `board.size`
- `pieceSlots`
- `pieceScanBoxes`
- `boardFillColor`, `pieceFillColor`, `colorThreshold`

Без калибровки бот может ставить фигуры мимо клеток.

## Как улучшить стабильность

- Добавить multi-color распознавание фигур (несколько оттенков на каждый цвет).
- Тонко подкрутить веса в `evaluateBoard` (линии/комбо/дыры/неровность/края) под вашу версию игры.
- Авто-обнаружение кнопки `Restart` после проигрыша (по шаблону картинки).
- Хранить профили калибровки под разные устройства.
